# 🌌 Telegram-Бот Воронка Продаж для Astrey.ru с интеграцией GigaChat ИИ 🌌

Добро пожаловать в репозиторий **самого мощного и полностью автоматизированного Telegram-бота воронки продаж** для твоего интернет-магазина звёздных карт, картин со звуком и фотопостеров **Astrey**! 🚀

Этот бот работает на базе **официального искусственного интеллекта GigaChat от Сбера**, что позволяет ему без проблем и без использования зарубежных VPN общаться с российскими клиентами, снимать любые возражения и продавать ваши постеры на эмоциях!

---

## 🔥 Что делает этого бота «Пиздец каким мощным»?

### 1. 🧠 Интеллектуальный автоответчик на базе GigaChat (Сбер)
Каждый раз, когда пользователь заходит с сайта и задает вопрос (например: *«Как работает картина со звуком?»* или *«Сколько идет СДЭК до Екатеринбурга?»*), бот:
* Самостоятельно запрашивает токен GigaChat через OAuth Sber.
* Генерирует сочный, продающий и эмпатичный ответ, основываясь на твоей **базе знаний** и **профессиональном системном промпте**.
* К каждому сообщению крепит кнопки призыва к действию (CTA): **🌌 Запустить конструктор подарка** или **💬 Связаться с живым менеджером**.

### 2. 🔌 Live Chat CRM — Моментальный перехват диалога
Если клиент нажимает *"Связаться с живым менеджером"* или ИИ замечает, что клиенту нужен человек:
* Бот оповещает клиента: *"Я уже позвал нашего менеджера, он ответит в течение пары минут!"*.
* **Вам (в админку) прилетает мгновенный алерт с инлайн-кнопкой:** `[💬 Начать диалог с клиентом]`.
* При нажатии вы входите в режим **Live Chat**: все последующие сообщения, которые вы пишете в бот, пересылаются клиенту, а сообщения клиента — вам. 
* Вы общаетесь напрямую через интерфейс бота, берете оплату, допродаете, а затем пишите `/stopchat` для возврата бота в авторежим. Никаких сторонних программ не нужно!

### 3. 🛠️ Умный пошаговый конструктор & Апсейлы
Пользователь за пару секунд собирает свою картину прямо в чате:
* Указывает памятную дату 📅
* Город события (для точного звездного неба по каталогам NASA) 🏙️
* Текст надписи ✍️
* Отправляет голосовое сообщение или трек прямо в чат 🎵 *(для картин со звуком)*
* Кликает на размер (A4, A3, A2, XL), тип рамы и праздничную упаковку (тубус). Цены пересчитываются мгновенно в корзине!

## ⚙️ Настройка GigaChat API

Бот умеет работать с любыми авторизационными данными от Сбербанка:
1. Зайдите в ваш личный кабинет разработчика на [Sber Studio](https://developers.sber.ru/studio/).
2. Создайте проект и скопируйте ваши авторизационные данные.

Откройте файл `config.py` и заполните:
* `BOT_TOKEN` — Ваш токен от [@BotFather](https://t.me/BotFather).
* `GIGACHAT_AUTH_KEY` — Ваш **Ключ авторизации** (длинная Base64 строка).
* Если у вас есть отдельные `Client ID` и `Client Secret`, просто введите их в `GIGACHAT_CLIENT_ID` и `GIGACHAT_CLIENT_SECRET` — **бот сам автоматически закодирует их в Base64** при старте!

## 🚀 Как запустить бота?

### Способ 1. Автоматический запуск через скрипт (Рекомендуется)
Просто введите команду в консоли:
```bash
./run_bot.sh
```
Скрипт автоматически создаст виртуальное окружение `venv`, установит библиотеки, попросит токен бота и запустит сервер!

### Способ 2. Ручной запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте токены в `config.py`.
3. Запустите:
   ```bash
   python3 bot.py
   ```

## 🔑 Как пользоваться CRM и Админ-Панелью?

1. Чтобы стать администратором и получать алерты о заказах и вызовах клиентов, отправьте боту секретную команду:
   ```text
   /admin ASTREY_POWER_ADMIN_2026
   ```
2. Теперь вы авторизованы! Вам доступны функции по команде `/admin`:
   * **📊 Статистика:** сколько людей в базе, сколько заказов, общая выручка.
   * **📣 Рассылка:** массовая отправка акций и новостей всем пользователям.
   * **📦 Управление заказами:** переключение статусов заказов прямо в чате (клиент получит уведомление: *«Ваш заказ передан дизайнеру!»*).

3. **Работа в чате (CRM):**
   * Когда клиент позовет человека, нажмите кнопку `💬 Начать диалог с клиентом`.
   * Чтобы закончить диалог, отправьте команду `/stopchat` или нажмите инлайн-кнопку `❌ Завершить диалог`.
